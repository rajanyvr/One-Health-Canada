# One-Health-Canada
A website for discussing how to reduce Healthcare Delivery costs, improve service availability by increasing overall efficiency 
The Healthcare Delivery system in Canada at one time was often cited as a well run Uniersal Healthcare system.  For a number of reasons that perception has changed drastically and today in 2026 Cnadians face multipl challenges in securing the healthcare they need.
This project will document some of the shortcomings of Canada's healthcare system but more importantly the goal is to come up with proposals that can bring about improvements to the satisfaction of Canadians.
Any useful information that users can provide is certainly appreciated.  The central goal will always be to make meaningful improvements to today;s system for the benefit of Canadians
